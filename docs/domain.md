## Назначение

Система помогает учебному отделу и кафедрам распределить учебную нагрузку на учебный год:
какие дисциплины, у каких групп и в каком объёме ведёт каждый преподаватель, — и проконтролировать,
что нагрузка каждого соответствует его ставке.

## Роли

| Роль | Что делает |
|---|---|
| Учебный отдел (методист) | Ведёт справочники, нормы, учебные планы и контингент; контролирует нагрузку по всему вузу |
| Заведующий кафедрой | Распределяет поручения своей кафедры между преподавателями |
| Преподаватель | Смотрит свою нагрузку, индивидуальный план |
| Администратор | Пользователи, права, настройки организации |

## Глоссарий

| Термин | Значение | В коде |
|---|---|---|
| Кафедра | Подразделение, за которым закреплены преподаватели и дисциплины | `Department` |
| Преподаватель | Сотрудник кафедры с долей ставки | `Teacher` |
| Ставка | Доля полной занятости: 1,0; 0,75; 0,5; 0,25 | `Teacher.Rate` |
| Норма часов | Годовой объём нагрузки на 1,0 ставки | `WorkloadNorms.HoursPerRate` |
| Группа | Учебная группа студентов (контингент) | `StudentGroup` |
| Контингент | Число студентов в группе / в поручении | `StudentGroup.Students`, `Assignment.Students` |
| Поручение | Дисциплина, закреплённая за преподавателем для группы, с часами по видам занятий | `Assignment` |
| Виды занятий | Лекции, практические, лабораторные | `Assignment.Lectures / Practice / Labs` |
| Экзамен и консультация | Часы, вычисляемые по нормам из числа студентов | `Assignment.ExamHours` |
| Учебный план | Образовательная программа года набора | `StudyPlan` |
| Связь «план — группа» | Сколько студентов группы учится по плану (многие-ко-многим) | `PlanGroupLink` |
| Перегруз / недогруз | Фактические часы больше нормы / меньше порога от нормы | `LoadStatus` |

## Правила расчёта (реализованы)

1. **Норма преподавателя** = ставка × `HoursPerRate` (по умолчанию 600 ч).
2. **Часы экзамена** = `ConsultationHoursPerGroup` (2 ч) + `ExamHoursPerStudent` (0,33 ч) × число студентов,
   округление до 0,1 ч от нуля. Нет экзамена или студентов — 0.
3. **Итог поручения** = лекции + практические + лабораторные + экзамен.
4. **Статус**: больше 100 % нормы — перегруз; меньше `UnderloadThresholdPercent` (90 %) — недогруз; иначе норма.
5. Выбор группы в поручении подставляет её численность; число студентов можно уменьшить (подгруппа).
6. Новая связь «план — группа» по умолчанию забирает всех ещё не распределённых студентов группы, минимум одного.

Нормы задаются в `appsettings.json`, секция `Norms`.
